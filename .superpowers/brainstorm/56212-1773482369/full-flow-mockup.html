Design Details

🎨 Color Progression
Screen 1: Indigo (trust, family) → Screen 2: Purple (intelligence, AI) → Screen 3: Sky Blue (clarity, security)
✨ Animations (in SwiftUI)
Staggered entrance: headline → subtitle → card slides up. Card elements animate in sequence. Spring curves, not linear. Page dots morph smoothly.
🌙 Dark Mode
Background gradients shift to deep navy. Cards use .glass() modifier with .ultraThinMaterial. Accent colors stay vibrant. Orbs get stronger opacity.
🚀 Technical
Pure SwiftUI — no SceneKit, no GLTFKit2, no 3D models. Removes ~3 .glb files from bundle. Faster first-launch. Zero external dependencies for onboarding.
