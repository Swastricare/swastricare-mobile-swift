Home Screen Visual Refresh — Analysis

Current problems and what needs to change to match the new premium design language

1. No Visual Hierarchy — Everything Looks Equal

Current Home Screen Sections
Header — greeting + icons (flat, no depth)
3D Model + Stats — same background as everything else
Vitals Grid — same card style, same corners, same shadow
AR Body Scan — same card style again
Quick Actions — same card style again

Problems

  • Every section uses .glass(cornerRadius: 16) — no variation, no rhythm
  • No section "pops" as more important than others
  • The eye doesn't know where to look first
  • Feels like a list of cards, not a designed dashboard

2. Not Premium — Doesn't Match New Onboarding/Login

New Onboarding/Login
  • Bold type with accent-colored keywords
  • Glass cards with depth and layering
  • Gradient buttons (teal→green)
  • Staggered spring entrance animations
  • Rich background with colored orbs
  • Color storytelling (each screen has a purpose)
Current Home Screen
  • System font with no accent colors in headings
  • Flat .glass() on everything
  • No gradients — solid colors only
  • Basic opacity fade entrance
  • PremiumBackground but barely visible
  • No color meaning — all gray cards

3. Colors & Spacing Are Off

Specific Issues

  • Greeting header has too much vertical space, status badge is hard to read
  • Vitals cards use semantic colors (red/indigo/green) but they're tiny dots — no visual impact
  • Quick action buttons are all the same size/shape — Medication and Hydration should be more prominent (used daily)
  • 3D model section takes 320pt of height — too much for a decorative element
  • Spacing between sections is uniform — should breathe more between major zones

What should we enhance?

Greeting Header

5
