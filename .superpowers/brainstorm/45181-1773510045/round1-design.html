Rule: Each feature gets a color.opacity(0.08) background tint + color.opacity(0.12) border. Values and labels use the feature's semantic color. In dark mode, the tints go subtler (0.06 bg, 0.08 border).

B. Section Rhythm & Spacing

Before — Uniform 16pt gaps
Everything same gap — no breathing room
After — Grouped zones with varied spacing
Zone: Identity
Zone: Vitals
Zone: Actions
32pt between zones, 12pt within zones
Spacing rules:
• Between major zones: 32pt (Header → Vitals → Actions → Body Model)
• Within a zone: 12pt between cards
• Section labels: Optional uppercase tiny labels ("YOUR VITALS", "QUICK ACTIONS") to anchor zones

Changes: Bigger name (24pt bold), cleaner status line with dot indicator, rounded square icon buttons instead of circles, user avatar/initial with brand gradient border. Removes the heart emoji (too casual for premium feel).

D. Staggered Entrance Animations

Current: All sections fade in simultaneously with a basic opacity animation.
Proposed: Cascading reveal like the onboarding — each zone slides up with a spring curve and increasing delay:
0.00s → Header slides in
0.10s → Vitals zone slides up
0.20s → Body model fades in
0.30s → Quick actions grid slides up
Same .spring(response: 0.6, dampingFraction: 0.8) curves as onboarding for consistency.
